# リリースノート

App Store Connect の「このバージョンの新機能」に貼る文面を、バージョンごとに置く。
日本語のみ。アプリの文言が日本語しかないので、他の言語を出すと本体と食い違う。

書きかたは本体の方針と同じで、測った事実だけを書く。「効きます」「続けてください」
のような判断は入れない（`CLAUDE.md` の「No medical judgement, ever.」）。

## 1.1.0 (build 5) — 2026-09-12

提出する文面:

```
・設定を画面下のタブに移しました。どの画面からでも同じ場所から開けます。
・履歴のカレンダーを横にスワイプして、前の月・次の月へ移れるようになりました。
・月を送れるのは今月までにしました。記録できない先の月へは進みません。
・履歴の「今月に戻る」を、矢印から「今月」という文字に変えました。
・ダークモードで、ボタンや文字の色が背景に沈んで読みにくかったのを直しました。
```

### このバージョンの中身（提出はしない、こちらの控え）

build 4（`630678b` の再申請ぶん）からの差分。

| コミット | 内容 |
|---|---|
| `e7fde89` | ダークモードのアクセント色。`MainTabView` が固定色で根の `.tint` を上書きしていたため、タブ配下のアクセント色の文字が 1.7:1 まで落ちていた。上書きを外し、`AccentColor` をライト `#0A574A` / ダーク `#2FB79E` に選び直して 5.2〜5.6:1 にした |
| `b425726` | 設定を 4 つ目のタブに。右上のツールバーからは外した |
| `cca53f2` | 履歴の「今月」を `arrow.uturn.backward` から文字に。取り消しの記号に読めていた |
| `5e5ebde` | 履歴のカレンダーに横スワイプ |
| `8c1b930` | 月送りの上限を今月に |

背景画像は `280fbd2` で一度消して `d6a376d` で戻したので、差し引きで変わっていない。
