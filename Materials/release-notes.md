# リリースノート

App Store Connect の「このバージョンの新機能」に貼る文面を、バージョンごとに置く。
日本語のみ。アプリの文言が日本語しかないので、他の言語を出すと本体と食い違う。

書きかたは本体の方針と同じで、測った事実だけを書く。「効きます」「続けてください」
のような判断は入れない（`CLAUDE.md` の「No medical judgement, ever.」）。

提出する文面:

```
・平均の数え方を直しました。体調やメモだけを書いた日は、排便が 0 回だったのか書き忘れたのか記録からは分からないため、平均排便回数に入れないようにしました。これまでの記録の平均が変わることがあります。
・変化を一文で示す条件を、指標ごとの記録日数で判断するようにしました。日数が足りないときは数値だけを出します。
・グラフの折れ線が、記録のない日をまたいでつながっていたのを直しました。

・CSV のメモが「-」や「=」で始まると、表計算ソフトで本文が消えることがあったのを直しました。
・観察対象を削除するとき、一緒に消える実施の記録と写真の件数を確認するようにしました。
・端末の暦を「和暦」にしているとき、PDF だけ元号で出ていたのを西暦にそろえました。
・履歴のカレンダーが、日付をまたいだあとも先月を表示したままになることがあったのを直しました。
・ブリストルの選択やカレンダーの今日など、文字が薄くて読みにくかったところを直しました。
```

### このバージョンの中身（提出はしない、こちらの控え）

build 5 からの差分。コードレビューで見つけたバグをまとめて直した回で、機能の追加はない。

| コミット | 内容 |
|---|---|
| `be736bc` | 集計・書き出し・削除まわり 11 件。平均の分母、最小日数の指標別判定、変化率の丸め、PDF の実施三状態・日数不足の脚注・メモの改ページ、書き出しの打ち切りとディレクトリ競合、観察対象削除の確認、全削除の失敗報告、グラフの線の切れ目、まとめの重複行。未使用コード 10 件の削除も含む |
| `ac9d885` | 和暦端末で PDF だけ元号になっていた件。`Formatting` が locale だけ固定して暦を固定していなかった。`Calendar.startOfMonth` の `.era` 欠落も同時に直した |
| `48fb6f4` | 履歴の表示月が今日を追わない件と、CSV の数式解釈（`= + - @` で始まるメモ） |
| `12a01c7` | 読めないコントラスト 3 か所。ブリストルの選択 2.2:1、ダークの「今日」2.5:1、症状チップ 1.5:1 |

### 利用者の数値が変わること

`be736bc` の 2 件は、既存の記録の見え方を変える。

- 体調やメモだけ書いた日が平均排便回数の分母から抜けるので、**平均が上がる方向に動く**
- 最小日数の判定が指標ごとになったので、**断定文の一部が「日数不足」の断りに差し替わる**
  （「排便なし」の日が多い観察で顕著）

どちらも計算を正しくした結果だが、黙って数字が変わると「壊れた」と読まれうるので、
提出文面の 1 つ目と 2 つ目に書いてある。

### 版数の判断

今回は全部バグ修正で、機能の追加がない。1.1.0 のときに「機能の追加なのでパッチではなく
マイナー」と判断したのと同じ物差しで、こちらはパッチを上げた。
